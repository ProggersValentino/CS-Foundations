
generally the project structure is of the following:

### Default
```
	/projectName
	    projectName.sln
	    /Project_Src
	        Source Files
	        Project_Src.csproj
```

### Developing with unit tests
[unit test setup](Unit%20Testing.md)

```
	/projectName
	    projectName.sln
	    /Project_Src
	        Source Files
	        Project_Src.csproj
	    /Project_Src.Tests
	        Test Source Files
	        Project_Src.Tests.csproj
```
